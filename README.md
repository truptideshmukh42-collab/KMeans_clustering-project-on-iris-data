# 🌸 K-Means Clustering on Iris Dataset

## 📌 Project Overview
This project demonstrates **K-Means Clustering**, an unsupervised machine learning algorithm, using the Iris dataset. The algorithm groups similar iris flowers into clusters based on their flower measurements.

## 🎯 Objectives
- Understand unsupervised machine learning.
- Implement the K-Means clustering algorithm.
- Group iris flowers into clusters.
- Visualize the clusters using a scatter plot.
- Learn how clustering works with the Scikit-learn library.

## 📊 Dataset
The Iris dataset contains 150 flower samples with four numerical features.

| Feature | Description |
|---|---|
| Sepal Length | Length of the sepal |
| Sepal Width | Width of the sepal |
| Petal Length | Length of the petal |
| Petal Width | Width of the petal |

The dataset contains three species:
- Setosa
- Versicolor
- Virginica

**Note:** K-Means does not use the species labels to create clusters.

## 🛠️ Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## ⚙️ Algorithm Used
**K-Means Clustering**

K-Means is an unsupervised machine learning algorithm that divides data into a specified number of clusters based on similarities between data points.

In this project, the number of clusters is set to **3**.

### Steps
1. Load the Iris dataset.
2. Select the four numerical features.
3. Apply the K-Means algorithm.
4. Group the data into three clusters.
5. Visualize the clusters using a scatter plot.
